LATROBE END AR TEST

This folder contains index.html and targets.mind. Both must be uploaded together to a public HTTPS website, e.g. GitHub Pages, to use the phone camera. Opening index.html as a local file will not work reliably.

This is a test, not a finished seven-anchor experience. It uses the uploaded MindAR target and shows the approved Latrobe End story when the target is recognised. Recognition on the physical placemat has not yet been verified.

The page loads A-Frame and MindAR from public CDNs, so the phone needs an internet connection.
